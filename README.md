# Student-Management-System-CLI
I have completed OOP concepts and the Collection Framework (like ArrayList) and built an application using these.

I used two classes to implement the application:

Student class
StudentManagement class

These classes use OOP concepts and the ArrayList data structure.

In the Student class, I created fields and methods such as getters and setters.

The fields are set as private, which is called encapsulation.

I access private field data using getters, and I modify the data using setters. This helps protect the data.

Conclusion:
By using these concepts, I understood the basics of OOP. In the future, I will improve this project and fix its disadvantages.
